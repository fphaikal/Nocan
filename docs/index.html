A few little answers.

Is Nocan really free?

Yes. Nocan's original project code is available under the MIT license. You can use it, modify it, and contribute to it. Third-party dependencies and provider marks keep their own licenses and rights.

What do I need to run it?

A Windows desktop and graphics drivers supporting Direct3D 11 and Direct2D. Windows 11 is the primary development environment. Building from source also needs Rust and Windows build tools. macOS and Linux are not currently supported.

Where does my data go?

Task lists, settings, and hydration history are saved locally in your Windows user data folder. Lyrics, quotes, and optional artwork use external services. The usage panels read available local provider records. See the README for the complete integration details.

Can I choose what appears?

Yes. Enable the sections you use and hide the others. You can also change the mascot, notch behavior, theme, accent, font, and productivity preferences in Settings.
